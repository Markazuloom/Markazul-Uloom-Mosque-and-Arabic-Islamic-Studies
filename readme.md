# Markaz-ul-Uloom School of Arabic & Islamic Studies

Official website for Markaz-ul-Uloom School of Arabic & Islamic Studies, located in Alagbado, Lagos, Nigeria.

## About

Markaz-ul-Uloom has been serving the Muslim community since 1985, providing authentic Islamic education and fostering spiritual growth. We are celebrating our 40th anniversary in 2025.

## Website Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Dynamic Prayer Times**: Automatically updated prayer times for Lagos, Nigeria
- **Multi-language Support**: Content in English and Arabic
- **Interactive Navigation**: Single-page application with smooth transitions
- **Donation System**: Secure donation options for various causes
- **Event Calendar**: Information about upcoming events and programs
- **Contact Integration**: Multiple ways to get in touch

## Technical Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Styling**: Custom CSS with responsive design
- **Icons**: Font Awesome and custom icons
- **Fonts**: Google Fonts (Inter, Amiri)
- **API Integration**: Aladhan Prayer Times API
- **Deployment**: Netlify

## Features

### Dynamic Prayer Times
- Automatically fetches current prayer times for Lagos, Nigeria
- Updates daily at midnight
- Fallback times if API is unavailable
- Manual refresh option

### Responsive Design
- Mobile-first approach
- Optimized for all screen sizes
- Touch-friendly navigation
- Fast loading times

### SEO Optimized
- Meta descriptions and titles
- Structured data
- XML sitemap
- Robots.txt
- Social media meta tags
